# tarunchintakunta-portfolio

Interactive WebGL portfolio. Single self-contained `index.html` — no build step.

- Three.js r0.184 + Lenis via CDN importmap
- Procedural ASCII-grid background shader
- Holographic dithered model shader on a DRACO-compressed GLB
- Canvas-sampled particle name assembly
- 2400vh scroll-choreographed timeline

Open `index.html` in a browser.
